# Two-minute demo recording script

This is a recording plan, not a recorded video.

00:00–00:15 — “Atlas is an independent commercial analytics workbench. This demonstration uses 48 months of seeded synthetic pharmaceutical-style sales, not company records.” Show period, market and data disclosure.

00:15–00:35 — Show revenue, target attainment, signed gap, and the market review queue. Explain that target totals are joined after rep aggregation.

00:35–01:05 — Investigate Kuwait product contributions. Ask “What about Qatar?” Inspect the updated scope, result table and SQL. State clearly whether the planner is guided or live.

01:05–01:25 — Open Outlook. Compare ETS and seasonal-naïve test error. Explain that the future projection is exploratory and a sales drop does not prove a cause.

01:25–01:45 — Create a review brief; show its synthetic-data disclosure. Open Data assurance and the shared metric definitions.

01:45–02:00 — Show actual benchmark results and one limitation. Current guided performance is not LLM accuracy. Close with the decision supported: prioritize which commercial gaps warrant investigation.
